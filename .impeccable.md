## Design Context

### Users

Omarchy users who want the complete navigation, status, and control capability of the shell without a permanently dense top bar. They use Island throughout normal keyboard-and-pointer desktop work and expect stock Omarchy behavior to remain available while Island is developed or when an integration is incomplete.

### Brand Personality

Quiet, precise, and native. The interface should feel calm at rest, confident when it responds, and unmistakably part of the active Omarchy theme rather than like a separate application or ornamental skin.

### Aesthetic Direction

The creative north star is “a quiet aperture”: a minimal top-center surface that expands only as much as the current task requires. It inherits Omarchy color, typography, spacing, icons, and Hyprland geometry. The signature is a smooth, causal morph between real states. Avoid decorative motion, generic card-heavy dashboards, persistent clutter, invented branding, and visual claims that a delegated stock panel is Island-native.

### Design Principles

1. Stay nearly absent at rest and reveal completeness progressively.
2. Preserve stock behavior and honest fallbacks before improving presentation.
3. Make every morph explain a state change; keep motion smooth, decisive, interruptible, and reduced-motion safe.
4. Let the host own geometry, focus, dismissal, arbitration, and failure behavior while plugins own semantic state and actions.
5. Inherit the live Omarchy system by default and keep every development change reversible.
